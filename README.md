# Luis Salgado

### Implantación práctica de inteligencia artificial

Ayudo a profesionales y empresas a incorporar la IA a su trabajo diario: partimos de una tarea concreta y preparamos el contexto para convertirla en un proceso que se pueda revisar y mejorar.

Enseño a dirigir la IA como a un equipo: darle objetivos claros, acceso a la información necesaria y límites, y comprobar lo que entrega.

## En qué trabajo

- **Implantación de IA:** análisis de tareas, configuración de asistentes e integración con las herramientas del negocio.
- **Sistemas de trabajo con agentes:** memoria operativa y comprobaciones para mantener el control humano.
- **Formación aplicada:** aprender con tareas reales y materiales que se puedan seguir usando después.
- **Desarrollo a medida:** aplicaciones web e integraciones cuando el proceso lo necesita.

## Cómo trabajo

Primero, una tarea concreta y un criterio para saber si mejora. Después, una prueba acotada. La integración llega cuando podemos comprobar el resultado y saber cuándo necesita intervenir una persona.

Uso asistentes como Claude y ChatGPT, además de Gemini. Desarrollo las aplicaciones e integraciones con TypeScript o Python, según el proceso; trabajo con Next.js y Supabase.
